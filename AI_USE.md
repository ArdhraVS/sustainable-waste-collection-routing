# AI Use Record

## Tool
ChatGPT was used to assist with project planning, starter-code drafting, test design and documentation.

## Intended uses
- Modular Python structure for agent, search, CSP and knowledge-base components
- Synthetic JSON test scenario
- Explanation of algorithm assumptions and limitations
- Unit-test scaffolding

## Team verification required
Run all tests, inspect sample outputs, add at least three scenario tests, validate the constraints, and make sure every member can explain the algorithms. Edit and understand the code before submission.

## Important limitations
All road costs, bin fill levels and waste weights are synthetic. The route planner uses a nearest-next-stop heuristic, and the zero A* heuristic is correct but does not improve over UCS. Do not claim actual environmental savings based on simulated costs alone.
